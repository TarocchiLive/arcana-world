# Lumen UI Style

**安静的底层秩序，清楚的操作层级，一处有辨识度的视觉亮点。**

这是一套视觉语言，不是一张待复刻的页面。保留气质与关系，按产品任务重新选择布局、组件和表现手段。

## 风格骨架

- **低噪声分层**：通过表面明度、留白和对齐建立结构；边框、阴影、纹理作为补充，不同时争抢注意力。
- **克制强调**：大部分区域安静，少数焦点鲜明。颜色承担角色，不要求固定使用紫色或青色。
- **精密排版**：标题、正文、元信息形成可辨的节奏；对齐比装饰更重要，密度随任务变化。
- **轻量动态**：运动带来呼吸感或解释状态，不打断阅读。点阵、线框、渐变都只是可选语汇。
- **辨识度集中**：可以用独特字形、图形、色彩或转场形成记忆点；不必每一处都“有设计”。

## 迁移方法

先确定产品的核心任务与信息密度，再选表面、色彩、排版和动效。判断设计是否属于这一风格，看整体层级与节奏，而不是是否有星球、侧栏或计时器。

允许改变：明暗主题、强调色、布局拓扑、组件形态、插画类型、动效方式、实现框架。下列参考中的色值和尺寸是起点，不是验收硬指标。

# 视觉语言

## 表面关系

参考层级：环境底 → 内容表面 → 活跃区域 → 临时浮层。不要为了凑层级强行使用全部层级。

暗色版本以较小的明度差分隔大面积表面，让文字和关键动作承担对比。浅色版本可保留同样的低噪声关系，通过中性色、细分隔和局部强调实现；不应只是反转色值。

边框用于确认区域边界，阴影用于表达浮起，留白用于组织内容。按场景选用，不把三者叠成默认装饰。

## 颜色角色

| 角色 | 作用 | 暗色示例 |
|---|---|---|
| canvas | 环境底 | `#0B0D18` |
| surface | 内容承载 | `#15192B` |
| text | 主要内容 | `#F0F0FF` |
| muted | 次要信息 | `#929CB8` |
| separator | 低权重边界 | `#303852` |
| accent | 焦点与主要操作 | `#AB91FF` |
| secondary | 辅助视觉节奏 | `#65DDD0` |

这组紫青色只是参考。品牌色可替换 accent；暖色或冷色主题都成立。状态色与装饰色分开考虑，不必让辅助色永远代表成功。渐变适合塑造少量视觉焦点，不必铺满组件。

## 排版节奏

用少量明确层级区分：识别/标题、主要内容、辅助信息。优先通过字号、字重、颜色或间距中的一两项表达差异，避免每层同时变化全部属性。

工具型页面可以紧凑、等宽、对齐精确；阅读型页面可以舒展；展示型页面允许大字和大面积图形。三者通过低噪声背景和一致的层级关系保持家族感，而非共用同一字号和网格。

## 布局组合

按任务选择：
- 多任务切换：导航 + 内容区。
- 连续处理对象：列表 + 详情。
- 单一核心操作：聚焦画布 + 就近控制。
- 比较与选择：并列卡片或网格。

侧栏、卡片、图表、星球均非必需。宽度由内容的阅读长度和操作距离决定，不按固定列数无限拉伸。空白应表达分组或强调，而非替缺失内容占位。

## 视觉亮点

选一个主要识别手段：特殊排版、点阵/线框、品牌插画、精致图表或独特动效。写实图形、巨大标题也可以使用，只要符合当前产品的视觉重心；此前在某个工作台里不合适，不代表它们普遍被禁止。

缩小时保留任务关系：哪些内容必须同时可见，哪些可折叠或转入次级视图。不同平台不必共享同一布局，但应共享强调顺序。

# 弹幕与观众管理

登录后，Arcana World 自动连接你的直播间并开始接收弹幕。切换到其他页面时连接保持，返回后消息完整保留。

| 终端界面 | 网页面板 |
| --- | --- |
| 按 `2` 打开「弹幕」页 | 侧栏「弹幕」 |

![终端界面「弹幕」页，顶部一排是观众、大航海、房管等入口和对应按键](/images/arcana-world-02.webp)

## 查看弹幕 {#browse}

网页面板中直接滚动列表。向上翻阅时若有新消息，点击「最新消息」回到底部。

终端界面用方向键、`PgUp` / `PgDn` 或鼠标滚轮翻阅，`End` 回到最新一条。

列表默认只保留最近 30 条，更早的消息保存在本机历史中。如需保留更多，在「设置」→「行为」中修改「保留消息数」。

## 发送弹幕 {#send}

在页面底部的输入框中输入，按 `Enter` 发送。每条最多 40 个字。

终端界面先按 `/` 进入输入框，`Esc` 返回浏览。发送失败时草稿保留，修改后可直接重发。

## 回看历史 {#history}

该功能目前仅在终端界面中提供。

1. 在弹幕页按 `h`。
2. 填写「开始时间」和「结束时间」，格式如 `2026-11-05 20:00:00`，用 `Tab` 切换。
3. 按 `Enter` 查询，`Esc` 返回。

历史仅包含 Arcana World 运行期间收到的弹幕，程序未运行时发送的弹幕不会补录。

## 观众管理 {#moderation}

![说话人资料浮框，含禁言、加入黑名单、设为房管](/images/arcana-world-03.webp)

点击消息中的用户名，在弹出的资料中选择「禁言」「加入黑名单」或「设为房管」并确认。网页面板也可以右键点击消息，菜单中提供相同选项。

这些操作会直接修改你的 B 站直播间设置。禁言用于暂时限制对方发言；拉黑会限制对方发言、送礼等所有互动，限制范围更大。

按用户名或 UID 处理，或查看、撤销已有名单：

| | 终端界面（弹幕页） | 网页面板（「弹幕」页右侧） |
| --- | --- | --- |
| 房管 | 按 `m` | 「房管」 |
| 黑名单 | 按 `b` | 「黑名单」 |
| 禁言 | 按 `s` | 「禁言名单」 |

打开后输入用户名或 UID 查找，核对头像和 UID 后确认。禁言还需选择时长（若干小时或永久）。在名单中选中某人并确认即可撤销。

::: tip 提示
此处的禁言和拉黑作用于直播间，对所有观众生效。如只需在自己屏幕上隐藏某些内容，请使用[屏蔽词](/features/blocklist)。
:::

## 观众列表和大航海 {#viewers}

在网页面板「弹幕」页右侧点击「观众」或「大航海」；终端界面在弹幕页按 `u` 或 `g`。两个名单均显示前 20 名。

## 消息类型 {#events}

默认只显示与直播互动直接相关的消息：弹幕、礼物、醒目留言、大航海、进场、关注，以及开播下播、禁言等直播间通知。如需同时显示分享、抽奖、PK 进展等消息，在「设置」→「行为」中开启「显示其他事件」。

浮层和语音播报分别有独立的事件选择，见[弹幕浮层](/features/overlay)和[语音播报](/features/tts)。

## 暂停接收弹幕 {#listening}

在「设置」→「行为」中关闭「接收弹幕」。关闭后不再接收新消息，浮层、语音播报和 [WebSocket 广播](/features/websocket) 也随之停止输出。终端界面对应「设置」中的「登录后自动监听弹幕」。

收不到弹幕时，见[常见问题](/reference/troubleshooting#no-chat)。

::: details 本地历史的存储位置与删除
- 弹幕历史按直播间保存在数据目录的 `danmaku/history.db`（默认数据目录为 `~/.arcana/world`），仅保留最近 7 天，更早的记录自动清理。
- 被屏蔽词隐藏的消息同样保存在历史中。
- 如需立即删除全部历史，只能清除应用数据，此操作会同时删除设置、日志和登录信息。步骤见[数据目录与重置](/reference/data)。
:::

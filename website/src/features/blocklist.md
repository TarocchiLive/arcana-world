# 屏蔽词

屏蔽词用于在你的屏幕上隐藏包含指定词的消息，或仅禁止朗读这些消息。屏蔽词只影响本机的显示、语音播报和 WebSocket 广播，观众在直播间看到的内容不变。如需限制某个观众在直播间发言，请使用[禁言或拉黑](/features/chat#moderation)。

## 两份列表 {#lists}

| | 弹幕页和桌面浮层 | 语音播报 | [WebSocket 广播](/features/websocket) |
| --- | --- | --- | --- |
| 「全局屏蔽词」 | 不显示 | 不播报 | 不转发 |
| 「播报屏蔽词」 | 照常显示 | 不播报 | 照常转发 |

既不显示也不播报的词，加入「全局屏蔽词」；照常显示、仅不播报的词，加入「播报屏蔽词」。

## 添加和删除 {#add}

1. 在「直播台」找到「屏蔽词」卡片。
2. 在对应列表的输入框中输入，按 `Enter` 或点击「添加」。保存后立即生效。
3. 删除某个词时，点击词标签上的「×」。

![网页面板「直播台」中的「屏蔽词」卡片](/screenshots/web-blocklist.webp)

一次可添加多个词，用逗号、顿号、分号或换行分隔。例如输入 `加微信，代刷，免费领`，会保存为 3 个词。

终端界面在「直播间」页（按 `6`）选择「屏蔽词」，再选择列表，通过「＋ 添加屏蔽词…」添加；选中已有的词按 `Enter` 直接删除。

## 匹配规则 {#matching}

消息中包含该词即视为命中，无需整句一致，不区分大小写和全角半角。昵称、弹幕内容、礼物名均会检查，任一处命中，整条消息都会被隐藏或跳过。

因此，将某个观众的昵称加入「全局屏蔽词」后，其弹幕、礼物、进场消息均不再显示。

::: tip 提示
昵称过短容易误伤：其他用户昵称中包含这些字，或弹幕中提到该昵称，消息也会被隐藏。请尽量填写完整昵称。
:::

::: details 数量上限和保存位置
- 每份列表最多 200 个词，每个词最多 50 个字。重复的词只保留一个。
- 被隐藏的消息仍完整保存在本地弹幕历史中，删除屏蔽词后会重新显示在弹幕页。
- 「恢复默认设置」会保留屏蔽词，「清除应用数据」会将其删除。
- 屏蔽词保存在数据目录的 `config.json` 中（`blocklist` 下的 `global` 和 `tts`）。建议在程序中编辑，手动修改导致超出上限时，配置将读取失败。数据目录位置见[数据目录与重置](/reference/data)。
:::

# WebSocket 弹幕广播

## 启用与连接

在 TUI「设置」中设置「WebSocket 监听地址」，再开启「WebSocket 广播」。默认关闭，默认地址为 `127.0.0.1:7391`。地址使用 `IP:端口`，例如 `127.0.0.1:7391` 或 `[::1]:7391`，也接受 `localhost`；端口范围为 1 至 65535，主机部分必须填写。

地址和开关保存到 `config.json` 的 `websocket_addr`、`websocket_enabled`。广播运行时修改地址立即切换监听，原连接断开，客户端需连接新地址；绑定或保存失败时保留原服务。广播关闭时修改地址不会启动服务。

启动时端口被占用或凭据读取失败会显示警告，应用继续运行，广播开关显示关闭。可以修改地址后重新开启。

命令行 `--websocket-addr 127.0.0.1:7391` 仅本次运行覆盖地址并启用广播；此时界面不能修改地址，恢复默认设置也不会关闭当前广播。客户端连接 `ws://127.0.0.1:7391/ws`。WebUI 模式同样应用已保存的配置和命令行地址；广播设置目前在 TUI 中编辑。

需启用弹幕接收，并监听直播间。广播转发实时事件，不重放历史，不受 TUI 的显示数量限制影响。

广播使用[全局屏蔽词](blocklist.md)过滤昵称、弹幕内容、礼物名和其他事件文字，命中后整条消息不转发；播报屏蔽词不影响广播。保存屏蔽词后，后续消息立即使用新规则，无需重连。收到的原始消息仍完整保存到本地历史，移除屏蔽词不会补发之前被过滤的消息。

## 消息格式

每个 WebSocket 文本帧包含一个 JSON 对象：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `room_id` | 整数 | 事件所属直播间 ID |
| `event` | 对象 | B 站原始事件对象，保留原始字段，不转换为界面文本 |

转发范围沿用聊天页默认显示的事件，并包含分享、特别关注和互关：

- 弹幕、礼物（含批量礼物）、醒目留言及删除、上舰。
- 入场、关注、点赞、分享、特别关注、互关。
- 开播、停播、房间标题变更、切断、警告、禁言、房管变更和弹幕撤回。
- 对应的开放平台事件。

包括 `SUPER_CHAT_MESSAGE`、`SUPER_CHAT_MESSAGE_JPN`、`SUPER_CHAT_MESSAGE_DELETE`、`GUARD_BUY`、`USER_TOAST_MSG`、`USER_TOAST_MSG_V2`、`USER_TOAST_V2`、`SEND_GIFT_V2` 等命令。统计、榜单、未知事件及无法解析的事件不转发。

主命令按第一个冒号分割，例如 `DANMU_MSG:4:0:2:2:2:0` 也会转发，`cmd` 原值不变。过滤使用解码后的字段，发送时保留整帧原始 JSON；protobuf 字段仍保持上游的编码，批量消息仍是一帧，其中任一条命中屏蔽词则整帧不发送。

以下为精简的结构示例，不代表上游完整字段：

```json
{"room_id":12345,"event":{"cmd":"DANMU_MSG","info":[[],"你好",[67890,"用户",0]]}}
```

```json
{"room_id":12345,"event":{"cmd":"SEND_GIFT","data":{"uid":67890,"uname":"用户","giftName":"小心心","num":1}}}
```

弹幕正文通常位于 `event.info[1]`，发送者信息通常位于 `event.info[2]`；礼物信息位于 `event.data`。这些字段来自上游协议，可能变化或缺省，客户端应检查类型和字段存在性，并忽略不认识的字段。协议没有额外的版本号、序号或确认消息。

## 只读与断线

客户端无需发送订阅消息。服务仅广播，不接受发送弹幕或控制指令；客户端发送文本或二进制数据帧时，以关闭码 `1008` 断开。服务正常响应 Ping/Pong 心跳和关闭握手。每个客户端最多排队 64 条消息，队列满或单次写入超过 5 秒时断开。客户端自行重连，断线期间事件不会补发。

## 安全

访问令牌默认为空，不验证客户端。在 TUI「设置 → WebSocket 访问令牌」中设置，留空提交可关闭验证。令牌复用应用凭据存储，不写入 `config.json`；使用 memory 凭据后端时仅本次运行有效。恢复默认设置保留令牌，清除应用数据会删除令牌。

浏览器和 OBS 客户端连接 `ws://127.0.0.1:7391/ws?token=你的令牌`，令牌中的特殊字符需 URL 编码。支持自定义请求头的客户端也可发送 `Authorization: Bearer 你的令牌`，该请求头优先于查询参数。验证失败返回 HTTP 401；修改令牌会断开已有连接，客户端需使用新令牌重连。

默认只绑定本机；绑定 `0.0.0.0`、`[::]` 或局域网地址会向能访问该端口的设备开放服务，建议先设置随机长令牌。服务不提供 TLS，局域网传输的令牌和消息仍为明文；需加密时通过可信的 TLS 反向代理访问。

服务允许跨源连接，以支持 OBS 浏览器源。未设置令牌时，任意网页均可订阅其能访问的广播端口。带令牌的 URL 应视作凭据，避免公开或写入代理访问日志。
